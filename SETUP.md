# Где что лежит и как это запустить

Памятка о рабочем окружении FinBG. Состояние на 31.07.2026, всё проверено на
живой системе. Пароли, ключи и токены здесь не хранятся.

Про сам проект и логику данных — `PROJECT_NOTES.md`, про задачи — `PLAN.md`.

## Самое главное в двух словах

Программа состоит из трёх частей:

- **база данных и сервер** — на арендованном сервере (VPS), не на компьютере;
- **интерфейс** — собирается на компьютере и открывается в браузере;
- **исходные файлы Excel** — на сетевом диске `W:`, источник данных.

Чтобы начать работать, нужно поднять две вещи: **туннель к серверу** и
**dev-сервер интерфейса**. Обе команды ниже.

## Как поднять подключения

Обе команды — для **Windows PowerShell** (в нём `git` и `node` не прописаны в
путях, поэтому пути полные).

**1. Туннель к серверу.** Без него интерфейс покажет «Failed to fetch».
Окно не закрывать, туннель живёт, пока оно открыто:

```powershell
ssh -N -o ServerAliveInterval=15 -o ExitOnForwardFailure=yes -L 8000:localhost:8000 VPS
```

Туннель иногда рвётся сам по себе со стороны хостинга. Чтобы поднимался заново:

```powershell
while ($true) { ssh -N -o ServerAliveInterval=15 -o ExitOnForwardFailure=yes -L 8000:localhost:8000 VPS; Start-Sleep 3 }
```

**2. Интерфейс.** Запускается в фоне, окна не занимает:

```powershell
$node='C:\Users\admin\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe'
$env:WRANGLER_LOG_PATH='.wrangler/wrangler.log'
Start-Process -FilePath $node -ArgumentList 'C:\dev\finbg\web\node_modules\vinext\dist\cli.js','dev','--host','localhost','--port','5173' -WorkingDirectory 'C:\dev\finbg\web' -WindowStyle Hidden
```

**Проверить, что всё поднялось:**

```powershell
netstat -ano | findstr LISTENING | findstr ":5173 :8000"
```

Должно быть три строки: одна про порт 5173 и две про 8000. Если строк нет —
соответствующая часть не запущена.

## Арендованный сервер (VPS)

Подключение: `ssh VPS`. Адрес, пользователь и ключ прописаны в
`C:\Users\admin\.ssh\config`, отдельно вводить ничего не нужно.

| Что | Где |
|---|---|
| Серверная часть | `/opt/finbg/api` |
| Окружение Python | `/opt/finbg/venv` |
| Загрузчики данных | `/opt/finbg/imports` |
| Служба | `finbg-api` (`systemctl restart finbg-api`) |
| База данных | PostgreSQL, база `finbg`, пользователь `finbg` |

Запрос к базе: `sudo -u finbg psql -d finbg`.

Загрузчики лежат именно в `/opt/finbg/imports`, а **не** в `api/scripts` —
там их искать бесполезно.

## Выкладка изменений на сервер

`/opt/finbg/api` — **не** git-репозиторий. Выкладка идёт копированием файлов:

1. проверить синтаксис: `/opt/finbg/venv/bin/python -m py_compile <файл>`;
2. скопировать через `scp` во временную папку;
3. сделать копию текущего файла (`cp main.py main.py.bak-<дата>`);
4. положить на место и `systemctl restart finbg-api`.

Изменения базы (миграции) применять так:
`sudo -u finbg psql -d finbg -v ON_ERROR_STOP=1 -f <файл>`.
Перед применением — прогнать в отменяемой транзакции (`begin; \i файл; rollback;`),
чтобы увидеть результат, ничего не меняя.

**Правки в коде на сервер сами не попадают.** Пока не скопировали и не
перезапустили службу — на сервере работает старое.

## GitHub

Репозиторий: `git@github.com:nip1976-web/FInBG.git`, основная ветка `main`.

Отдельного ключа для GitHub нет — подходит **тот же** ключ, что и для VPS, но
его нужно указать явно, иначе будет «Permission denied»:

```powershell
$env:GIT_SSH_COMMAND='ssh -i C:/Users/admin/.ssh/id_ed25519_vps2parser -o IdentitiesOnly=yes'; & "C:\Program Files\Git\cmd\git.exe" -C C:/dev/finbg push origin main
```

Отправку на GitHub делает Николай: помощнику её обычно блокирует защита прав.

## Грабли

Список того, на чём уже теряли время.

**Библиотеки интерфейса — ссылка, а не папка.** `C:\dev\finbg\web\node_modules`
указывает на библиотеки во втором клоне (`FInBG-latest`). Сделано, чтобы не
дублировать 681 МБ. Поэтому **второй клон удалять нельзя** — интерфейс перестанет
запускаться. Если он всё же понадобится под удаление, сначала выполнить
`pnpm install` в `C:\dev\finbg\web`. Старые библиотеки отодвинуты в
`web\node_modules.old-2026-07-31`, их удалить можно.

**Правки интерфейса больше не нужно никуда копировать.** Раньше dev-сервер
работал из чужого каталога и правки до браузера не доходили; с 31.07.2026 он
работает из `C:\dev\finbg\web`. Если правка не видна — сначала полная
перезагрузка страницы (Ctrl+Shift+R), потом уже искать ошибку.

**«Failed to fetch» в интерфейсе — это почти всегда упавший туннель**, а не
ошибка в коде. Сначала проверить туннель.

**`git` и `node` не прописаны в путях PowerShell.** Команды для Николая писать
с полным путём (`& "C:\Program Files\Git\cmd\git.exe"`), разделитель `;`, а не
`&&` — иначе будет ошибка про недопустимый разделитель.

**Счета в евро оплачиваются в рублях**, поэтому сумма счёта и сумма платежа
законно не совпадают — сверять по сумме нельзя.

**Номер счёта в назначении платежа ненадёжен.** Привязывать платёж к сделке
только если совпадает и номер, и клиент.

- Не выкладывать на сервер, не сделав копию заменяемого файла.
